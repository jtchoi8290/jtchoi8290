1. Go to https://nodejs.org

3. Open the downloaded file → Continue → Continue → Agree → Install → enter

4. When finished, fully close any open Terminal/Command Prompt windows.

How to verify it worked:
- Mac: Open Terminal (Cmd + Space, type "Terminal", hit Enter)
- Windows: Open Command Prompt (Windows key, type "cmd", hit Enter)

    node -v

If you see something like "v22.11.0", you're done. ✅

--------------------------------------------------------------------------------

Expo Go is the app that will run our project on your phone.

- iPhone:  https://apps.apple.com/app/expo-go/id982107779

--------------------------------------------------------------------------------
🆘 BizEmail Workshop — Common Errors
--------------------------------------------------------------------------------

▸ "command not found: npm" or "command not found: node"
  Cause: Node.js wasn't installed, or Terminal hasn't picked it up.
  Fix:
  1. Verify install at https://nodejs.org (LTS version)
  2. Quit Terminal completely (Cmd+Q on Mac, close window on Windows)
  3. Reopen Terminal → try "node -v" again
  4. If still missing: tell instructor

--------------------------------------------------------------------------------

▸ "command not found: git"
  Cause: Git is missing from your Mac.
  Fix (Mac):     In Terminal type "xcode-select --install" → click Install
                 when prompted. Wait 5 min. Retry.
  Fix (Windows): Install from https://git-scm.com/download/win

--------------------------------------------------------------------------------

▸ "cd: no such file or directory: ~/jtchoi8290/server"
  Cause: You're not in the right place.
  Fix:
      cd ~
      ls
  Do you see "jtchoi8290"? If not, you didn't clone yet — go back to Slide 8.

--------------------------------------------------------------------------------

▸ EMFILE: too many open files (Mac only)
  Cause: macOS file-watcher limit.
  Fix: In Terminal type:
      brew install watchman
  Then retry "npm start". If "brew" is also missing: tell instructor.

--------------------------------------------------------------------------------

▸ Phone says: "Project incompatible with this version of Expo Go"
  Cause: Expo Go updated; the project needs adjustment.
  Fix: Tell the instructor — this is a 1-min fix from the instructor's machine.

--------------------------------------------------------------------------------

▸ Phone says: "Could not connect to development server"
  Cause: Phone and laptop are not on the same Wi-Fi, or wrong IP in app.json.
  Fix:
  1. Confirm both devices are on the venue's main Wi-Fi (not "guest")
  2. Re-run "ipconfig getifaddr en0" (Mac) or "ipconfig" (Windows)
  3. Update app.json with the correct IP
  4. In Terminal 2 press Ctrl+C, then "npx expo start --clear"
  5. Re-scan QR

--------------------------------------------------------------------------------

▸ App opens but Compose Email fails with "401" or "authentication"
  Cause: Your API key isn't loaded.
  Fix:
      cat ~/jtchoi8290/server/.env
  Does it show your real key starting "sk-ant-api03-..."? If not, edit it.
  Then in Terminal 1: Ctrl+C → "npm run dev" (restarts the backend).

--------------------------------------------------------------------------------

▸ App says "Your credit balance is too low"
  Cause: Anthropic account has no money.
  Fix: https://console.anthropic.com → Plans & Billing → Add $5.

--------------------------------------------------------------------------------

▸ White screen on phone forever
  Cause: Cache corruption.
  Fix: In Terminal 2: Ctrl+C → "npx expo start --clear". Scan QR again.

--------------------------------------------------------------------------------

▸ "I just want to start over"
  Close both terminals. Reopen Terminal. Then:
      cd ~/jtchoi8290/server
      npm run dev
  In a SECOND terminal:
      cd ~/jtchoi8290/app
      npm start

--------------------------------------------------------------------------------

▸ Still stuck after trying the above?
  🙋 Raise your hand. That's why the instructor is here. Don't suffer in
  silence — you're not slowing anyone down.
